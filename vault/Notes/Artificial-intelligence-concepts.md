# Artificial-intelligence-concepts

## Summary

Artificial Intelligence (AI) enables machines to perform tasks requiring human intelligence. It includes branches like Machine Learning, Deep Learning, and applications such as recommendation systems and autonomous vehicles.

Artificial Intelligence (AI) is the field of study that enables machines to perform tasks that typically require human intelligence. The core branches of AI include Machine Learning, Deep Learning, Computer Vision, Natural Language Processing, and Robotics. Machine Learning is a subset of AI that allows computers to learn patterns from data rather than relying on explicitly programmed rules. Common algorithms in Machine Learning include Linear Regression, Logistic Regression, Random Forest, XGBoost, and Support Vector Machine. AI has various applications such as recommendation systems, fraud detection, medical diagnosis, chatbots, and autonomous vehicles. Key terms in AI include dataset, features, labels, training, inference, and accuracy. Understanding these concepts is essential for grasping the fundamentals of AI and its practical implementations.

- [[XGBoost]] (medium): An optimized gradient boosting algorithm that provides high accuracy and performance for various machine learning tasks.

## Definitions

- [[Dataset]]: A collection of data used for training or testing machine learning models.
- [[Features]]: Individual measurable properties or characteristics of data points used in machine learning.
- [[Labels]]: The target variable or output that the machine learning model is trained to predict.
- [[Training]]: The process of using a dataset to adjust the parameters of a machine learning model to improve its performance.
- [[Inference]]: The process of using a trained machine learning model to make predictions on new, unseen data.
- [[Accuracy]]: A measure of how often a classification model makes correct predictions, calculated as the ratio of correct predictions to total predictions.
