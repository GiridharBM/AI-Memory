# OpenHands Platform for AI Developers

## Summary

OpenHands is an open-source platform enabling AI agents to interact with the world like human developers, supporting code writing, CLI interaction, and web browsing. It facilitates agent development, sandboxed execution, and benchmark evaluation.

OpenHands (formerly known as OpenDevin) is a platform for developing AI agents that can interact with the environment in ways similar to human developers. It allows for the creation of new agents, safe execution in sandboxed environments, coordination between agents, and integration of evaluation benchmarks. The platform supports tasks like software engineering (e.g., SWE-BENCH) and web browsing (e.g., WEBARENA). It is released under the MIT license and is a community project with over 2.1K contributions from more than 188 contributors. The paper introduces its architecture, capabilities, and evaluations across 15 challenging tasks, emphasizing its role in advancing AI agent development for complex software tasks.
