## Key Concepts

- [[Large Language Model]] (high): A neural network trained to predict the next term in an input sequence. It processes text by tokenizing it into discrete units and using vectorization to represent meaning.
- [[Tokenization]] (high): The process of breaking down text into discrete tokens, which are the smallest units of meaning. Tokens help in understanding the structure of natural language.
- [[Vectorization]] (high): Converting tokens into vectors that represent their meaning in a multidimensional space. This allows models to understand and generate text based on semantic relationships.
- [[Attention]] (high): A mechanism that allows models to focus on relevant parts of input text by considering contextual information from surrounding words, enabling better understanding of ambiguous terms.
- [[Self-Supervised Learning]] (high): A training method where models learn from the structure of input data without explicit labels, making use of the inherent patterns in text to predict missing parts.
- [[Transformer]] (high): An algorithm that processes input tokens through attention blocks, allowing models to capture complex relationships and context in text.
- [[Fine-tuning]] (high): A process where a pre-trained model is adapted to a specific domain or task by training it on a targeted dataset, improving its performance for specialized applications.
- [[Few-shot Prompting]] (high): A technique where a model is provided with a few examples to guide its response, enhancing its ability to generate accurate and contextually appropriate outputs.
- [[Retrieval Augmented Generation]] (high): A method that combines a large language model with a vector database to retrieve relevant documents and augment the query context, improving the quality of generated responses.
- [[Vector Database]] (high): A database that stores and retrieves documents based on semantic similarity, using vector representations to find relevant information efficiently.
