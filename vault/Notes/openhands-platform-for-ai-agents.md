# openhands-platform-for-ai-agents

## Summary

OpenHands is an open platform for AI developers to create agents that interact with the world like human developers through coding, command line, and web browsing. It supports sandboxed environments, multi-agent coordination, and benchmark evaluations.

OpenHands (formerly OpenDevin) is a platform designed for developing AI agents that mimic human developers by executing code, interacting with command lines, and browsing the web. The platform enables the creation of new agents, safe code execution in sandboxed environments, coordination between multiple agents, and integration of evaluation benchmarks. It has been evaluated on 15 challenging tasks, including software engineering (like SWE-BENCH) and web browsing (like WEBARENA). OpenHands is released under the MIT license and is a community-driven project with over 188 contributors and 2,100+ code contributions. The paper introduces the platform's capabilities and its potential in advancing AI agent development.
