## Frequently Asked Questions

**Q1: Why does the greedy approach fail for the knapsack problem?**
A1: Greedy approach fails for 0/1 knapsack as it doesn't consider the global optimal solution, while fractional knapsack can be solved with greedy.

**Q2: What is the main difference between Bellman-Ford and Dijkstra's algorithm?**
A2: Bellman-Ford can handle negative weights and detect negative cycles, while Dijkstra's algorithm cannot handle negative weights.

**Q3: How does the Floyd-Warshall algorithm work?**
A3: Floyd-Warshall uses dynamic programming to compute all pairs shortest paths by considering each node as an intermediate point.

**Q4: When is dynamic programming preferred over greedy algorithms?**
A4: Dynamic programming is preferred when the problem requires optimal substructure and overlapping subproblems, which greedy algorithms may not handle.

**Q5: What is the time complexity of the Floyd-Warshall algorithm?**
A5: The time complexity of Floyd-Warshall algorithm is O(V^3) where V is the number of vertices.

**Q6: What is the key advantage of dynamic programming over greedy algorithms?**
A6: Dynamic programming guarantees an optimal solution by considering all subproblems, while greedy algorithms may not always find the optimal solution.

**Q7: What is the main limitation of the greedy algorithm?**
A7: The main limitation of the greedy algorithm is that it may not always find the optimal solution as it makes locally optimal choices without considering the global impact.

**Q8: How does the Bellman-Ford algorithm detect negative cycles?**
A8: Bellman-Ford detects negative cycles by relaxing all edges V-1 times and then checking if further relaxation is possible.

**Q9: What is the time complexity of Dijkstra's algorithm?**
A9: The time complexity of Dijkstra's algorithm is O((V + E) log V) when using a priority queue.

**Q10: Why is the Floyd-Warshall algorithm suitable for dense graphs?**
A10: Floyd-Warshall is suitable for dense graphs because its time complexity is O(V^3), which is efficient for graphs with a large number of edges.

## Long Answer Questions

**1. Explain the difference between the greedy approach and dynamic programming in solving optimization problems.**

The greedy approach makes locally optimal choices at each step, hoping to find a global optimum, while dynamic programming breaks down the problem into subproblems, solves them optimally, and stores results to avoid redundant computation. Greedy algorithms are faster but may not always yield the optimal solution, whereas dynamic programming guarantees an optimal solution but may be slower due to increased memory usage and computation.

**2. Compare the Bellman-Ford and Dijkstra's algorithms for finding shortest paths in a graph.**

Bellman-Ford can handle negative weights and detect negative cycles, while Dijkstra's algorithm cannot handle negative weights. Bellman-Ford has a time complexity of O(VE), and Dijkstra's has O((V + E) log V). Bellman-Ford uses dynamic programming and relaxes all edges V-1 times, while Dijkstra's uses a priority queue to select the minimum distance node.

**3. Discuss the advantages and disadvantages of the Floyd-Warshall algorithm for finding all pairs of shortest paths.**

Floyd-Warshall is suitable for dense graphs and can handle negative weights, but its time complexity of O(V^3) makes it inefficient for large graphs. It computes all pairs of shortest paths efficiently using dynamic programming, but the high time complexity limits its use for graphs with a large number of vertices.

**4. Explain how the Knapsack problem can be solved using dynamic programming and why the greedy approach fails.**

The 0/1 knapsack problem is solved using dynamic programming by considering each item and weight capacity, storing optimal solutions for subproblems. Greedy approach fails because it may not select the optimal combination of items, as it chooses items based on value/weight ratio without considering the global impact.

**5. What are the key characteristics of dynamic programming and how do they differ from greedy algorithms?**

Dynamic programming uses optimal substructure and overlapping subproblems, storing results to avoid redundant computation. Greedy algorithms make locally optimal choices without considering future steps, which may not lead to a globally optimal solution. Dynamic programming guarantees an optimal solution, while greedy algorithms may not.
