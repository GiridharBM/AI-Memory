## Key Concepts

- [[Agile]] (high): An iterative and collaborative approach to software development emphasizing flexibility, adaptability, and customer satisfaction. In DevOps, Agile methodologies like Scrum or Kanban enable continuous feedback and rapid iterations.
- [[CI/CD]] (high): A set of practices enabling frequent automated software releases. Continuous Integration ensures early issue detection through automated testing, while Continuous Delivery automates deployment processes for reliable and frequent production releases.
- [[Configuration Management]] (high): Managing and maintaining consistent software and infrastructure configurations through tools like Puppet or Ansible to automate and control changes.
- [[Deployment]] (high): Automating the process of releasing software into production environments to reduce manual intervention and ensure consistency across environments.
- [[Elasticity]] (high): The ability to scale computing resources dynamically based on demand using cloud or containerization technologies for optimal performance and cost efficiency.
- [[Git]] (high): A distributed version control system enabling collaboration, tracking changes, and managing source code repositories with features like branching and merging.
- [[Infrastructure as Code (IaC)]] (high): Defining infrastructure configurations in code using tools like Terraform or CloudFormation to automate, version, and manage infrastructure deployments.
- [[Incident Management]] (high): Responding to and resolving service disruptions to minimize downtime and prevent future incidents through post-incident analysis.
- [[Infrastructure Monitoring]] (high): Collecting and analyzing infrastructure data to ensure performance, availability, and reliability using monitoring tools.
- [[Jenkins]] (high): An open-source automation server for building, testing, and deploying software with a plugin ecosystem for extensibility.

## Frequently Asked Questions

- **Q:** What is CI/CD in DevOps?
  **A:** CI/CD stands for Continuous Integration/Continuous Delivery, a set of practices enabling frequent automated software releases. Continuous Integration ensures early issue detection through automated testing, while Continuous Delivery automates deployment processes for reliable and frequent production releases.
- **Q:** What is Infrastructure as Code (IaC)?
  **A:** Infrastructure as Code is an approach where infrastructure provisioning and management are treated as code artifacts using declarative or programmable formats, enabling automation, consistency, and versioning of infrastructure deployments.
- **Q:** What is Git used for in DevOps?
  **A:** Git is a distributed version control system used for tracking changes, managing repositories, and enabling collaboration in software development. It supports features like branching, merging, and conflict resolution, essential for DevOps workflows.
- **Q:** What is Kubernetes?
  **A:** Kubernetes is an open-source container orchestration platform that automates containerized applications' deployment, scaling, and management, providing a framework for managing containers across multiple hosts.
- **Q:** What is the purpose of a DevOps Pipeline?
  **A:** A DevOps Pipeline is a series of interconnected steps and actions orchestrated to build, test, and deploy software applications, enabling continuous Integration and Delivery through automated processes.
- **Q:** What is Observability in DevOps?
  **A:** Observability is the practice of gaining insights into a system's internal state and behavior by analyzing outputs, logs, metrics, and traces, crucial for understanding application and infrastructure health, performance, and behavior.
- **Q:** What is Microservices architecture?
  **A:** Microservices is an architectural approach where applications are built as a collection of small, independent services that work together to deliver specific functionalities, enabling flexibility, scalability, and resilience in complex applications.
- **Q:** What is Version Control in DevOps?
  **A:** Version Control, or Source Code Management, tracks and manages changes to source code files using systems like Git or Subversion, enabling collaboration, maintaining a history of changes, and facilitating easy integration and rollback of code changes.
