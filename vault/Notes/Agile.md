A glossary of DevOps terms covering Agile, CI/CD, Configuration Management, and other key concepts.

Each term is explained with its role in DevOps practices, emphasizing automation, collaboration, and continuous improvement in software development and operations.

## Key Concepts

- [[Agile]] (high): An iterative and collaborative approach to software development emphasizing flexibility, adaptability, and customer satisfaction. In DevOps, Agile methodologies like Scrum or Kanban deliver software in short cycles for continuous feedback and rapid iterations.
- [[CI/CD]] (high): A set of practices enabling frequent automated software releases. Continuous Integration automatically builds and tests code changes, while Continuous Delivery automates release and deployment processes for reliable and frequent production deliveries.
- [[Configuration Management]] (high): Managing and maintaining consistent software and infrastructure configurations. It involves tracking changes, ensuring consistency across environments, and using tools like Puppet or Ansible to automate configuration management.
- [[Deployment]] (high): The process of releasing software into production environments. DevOps focuses on automating deployment to reduce manual intervention and ensure consistency across environments.
- [[Elasticity]] (medium): The ability to scale computing resources dynamically based on demand, using cloud or containerization technologies for real-time resource allocation and cost efficiency.
- [[Git]] (high): A distributed version control system used for collaboration, tracking changes, and managing source code. It supports branching, merging, and conflict resolution for efficient distributed team work.
- [[Infrastructure as Code (IaC)]] (high): Treating infrastructure provisioning as code, defining configurations in declarative or programmable formats. Tools like Terraform or CloudFormation automate infrastructure deployments for consistency and versioning.
- [[Incident Management]] (medium): Responding to and resolving service disruptions. DevOps practices focus on minimizing downtime, restoring services quickly, and learning from incidents to prevent future occurrences.
- [[Infrastructure Monitoring]] (medium): Collecting and analyzing data from infrastructure components to ensure performance, availability, and reliability. Monitoring tools provide visibility into infrastructure health and potential issues.
- [[Jenkins]] (medium): An open-source automation server for building, testing, and deploying software. It supports CI/CD workflows with a plugin ecosystem for extensibility and adaptability.
