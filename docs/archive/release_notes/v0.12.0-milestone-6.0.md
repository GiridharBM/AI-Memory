# Release Notes — v0.12.0 (Phase 6: Production Hardening & Final Validation)

**Released:** 2026-08-09
**Phase:** Phase 6 — engineering reviews `docs/PHASE_6_P6-101..105_ENGINEERING_REVIEW.md` (all APPROVED) and the final project approval `docs/PHASE_6_FINAL_APPROVAL.md`

## What's New

- **Failure isolation** (P6-103) — a child attachment's processing failure no longer aborts the parent document (`app/pipelines/ingest_workflow.py`), and a manifest save failure keeps a processed item DONE instead of returning it to PENDING and re-processing it forever (`app/queue/worker.py`). Locked by +2 tests. Previously a single bad attachment could fail an entire ingestion batch, and an unwritable manifest could cause an infinite reprocess loop.
- **Security & configuration audit** (P6-104) — `PyMuPDF>=1.24.0` and `openpyxl>=3.1.0` added to `requirements.txt` so the documented `pip install -r requirements.txt` path no longer breaks scanned-PDF OCR or silently loses `.xlsx` tables; `test_production_environment_separates_logging_defaults` locks the production/development config separation.
- **Runtime-data hygiene** (P6-104) — 34 personal runtime files (inbox/processed/failed/manifests) untracked from git via `git rm --cached`; `.gitignore` extended to all five runtime directories (`.gitkeep` whitelist preserved). Files remain on disk; no behavior change.
- **Independent end-to-end validation** (P6-105) — 25/25 automated checks exercised the live application across all 15 flows and 10 non-functional dimensions (ingestion through hybrid retrieval; determinism, metadata preservation, offsets, rollback, feature toggles, empty/malformed/large inputs, no-result, recovery).
- **Final project approval** (P6-106).
