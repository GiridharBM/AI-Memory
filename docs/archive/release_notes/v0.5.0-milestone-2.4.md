# Release Notes — v0.5.0 (Milestone 2.4: Table Intelligence)

**Released:** 2026-08-03
**Milestone:** Phase 2, Milestone 2.4 — see `docs/PHASE_2_MILESTONE_2_4_ENGINEERING_SPECIFICATION.md` (v1.1 + remediation review R1–R4/C1–C3)

---

## What's New

- **Table intelligence subsystem** — `app/infrastructure/document_intelligence/tables/` with `TableExtractor` protocol + `TableExtractorRegistry` (`source_kinds` → extractor; empty registry / unknown kind → `None`, never raises). Composition root exposes `extract_tables(document)`, `get_table_extractor(...)`, `get_default_table_extractor()`.
- **Typed table models** — `Table` / `TableCell` / `TableRow` / `TableHeader` pydantic models (additive, `extra="forbid"`) with `source_position` provenance (line / sheet / page).
- **CSV/TSV extractor** — `csv.Sniffer` dialect sniff (fallback `csv.excel`), header sniffing, quoted/escaped field parsing, row/column caps.
- **Spreadsheet extractor** — per-sheet tables via openpyxl (loaded non-read-only with `data_only=True` so `merged_cells.ranges` is available); merged-cell rectangles flattened by propagating the top-left value.
- **PDF extractor** — pdfplumber default engine, camelot optional plugin with fallback (ADR-002); engine/formats missing → logged warning + empty list (flat fallback, C-3).
- **Markdown rendering** — `MarkdownTableRenderer` + `render_tables_to_markdown`: GitHub-flavored Markdown pipe tables with `\|` and newline (`<br>`) escaping; empty tables render to `""`.
- **Enrichment into the surviving document** — `_run_routed_processor` gained a `kind` parameter; after structure enrichment it calls `_enrich_tables` and stores `document.metadata.extra["tables"] = [table.model_dump(mode="json")]` when `tables.enabled` AND the classifier `kind` is `csv`/`spreadsheet`/`database`/`pdf` (R2). Best-effort: failures logged, key absent, flat text preserved.
- **Note-body rendering** — `ObsidianMarkdownGenerator` renders a `## Tables` section (after Categories) from `metadata.extra["tables"]`; absent/empty tables key → Phase-1-identical note output (AC5).
- **Configuration** — `intelligence.tables.*` block (`enabled`, `pdf_engine`, `max_rows`, `max_cols`, `header_sniffing`) bound in `TableSettings`; `enabled: true` by default. The frozen §2.4 `min_confidence` key was removed (review R1 — pdfplumber exposes no per-table confidence; deviation recorded in the M2.4 remediation report).
- **Dependencies** — `openpyxl>=3.1.0` promoted to core deps; `pdfplumber>=0.11.0` added to the `intelligence` optional extra (wheel preflight verified for `cp314-win_amd64`).

## Behavior Changes

- CSV/spreadsheet/PDF documents now carry a `metadata.extra["tables"]` list when the flag is enabled (default `true`) and their note output includes a `## Tables` section (after Categories).
- `intelligence.tables.enabled: false` (or non-table kinds, or engine failure) restores Phase-1-identical flat notes — no `"tables"` key, no `## Tables` section (R-4).
- `ProcessedDocument` is unchanged — tables ride the R-1 `metadata.extra["tables"]` channel, the same channel M2.3 uses for `structure`.
- `spreadsheet_ingestor.py` is unchanged — flat text preserved in both modes; structured tables attach only at the enrichment stage (spec R3).
- **Default-enabled user-visible change:** CSV/spreadsheet/PDF notes now include table sections out of the box.

## Requirements

- **Core:** `openpyxl>=3.1.0` (now declared as core).
- **Optional (`intelligence` extra):** `pdfplumber>=0.11.0` — required only for PDF table extraction; when absent, PDFs degrade to flat notes with a logged warning.

## Known Issues

- **`database` kind has no extractor (D5):** the flag triggers `_enrich_tables`, the registry returns `None` → no tables, flat text preserved. An extractor can be registered behind the same interface when a consumer exists.
- **PDF engine absent in this dev environment:** the engine-present path is covered by the integration-gated `test_engine_present_extracts_ruled_table` (`pytest.importorskip("pdfplumber")`); the degraded path is strictly enforced by `test_absent_engine_degrades_to_flat_fallback` (import forced to fail via monkeypatch — enforceable in every environment, review R2).
- **R2 fixture fix:** `ruled_table.pdf` regenerated as a genuine ruled table (ReportLab GRID strokes — pdfplumber sees 8 lines); the engine-present test asserts ≥ 1 `Table` + `| --- |` Markdown, proving the P2-405 AC.

## Rollback
